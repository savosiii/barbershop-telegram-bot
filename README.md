# Бот записи для барбершопа

Бот, который сам принимает записи: клиент выбирает услугу, день и время —
и готово. Владельцу приходит уведомление, а клиенту накануне визита —
напоминание, чтобы не пропустил.

## Что умеет

- **Запись в несколько тапов** — услуга → дата → свободное время. Занятое время не показывается.
- **«Мои записи»** — клиент видит свои записи и отменяет их сам, без звонков администратору.
- **Напоминания за день до визита** — клиенты реже пропускают запись, а мастер не теряет деньги на пустых окнах.
- **Команды для владельца**: `/today` — кто придёт сегодня, `/week` — расписание на неделю.
- **Прайс и контакты** — всегда под рукой в меню.
- **Уведомления владельцу** — о каждой новой записи и отмене.

Технически: Python + aiogram 3, состояния диалога (FSM), SQLite — вся база в одном файле, удобно бэкапить и переносить на любой хостинг.

## Как запустить

```bash
pip install -r requirements.txt
```

Рядом с `bot.py` создайте файл `.env`:

```
BOT_TOKEN=токен_от_BotFather
OWNER_ID=ваш_телеграм_id
```

Токен выдаёт [@BotFather](https://t.me/BotFather), а свой id можно узнать у @userinfobot.

```bash
python bot.py
```

## Под свой бизнес

Услуги и цены правятся в словаре `SERVICES`, рабочие часы — в списке `TIMES`, тексты — прямо в обработчиках. Обычно это 15 минут на кастомизацию.
