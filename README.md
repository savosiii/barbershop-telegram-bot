# Бот записи для барбершопа

Telegram-бот для приёма записей: клиент выбирает услугу → дату → свободное время,
владельцу приходит уведомление, клиенты получают напоминание за день до визита.

## Возможности

- Запись клиента по шагам (услуга, дата, время) с проверкой занятости слота
- «Мои записи» — просмотр и отмена своих записей клиентом
- Прайс и контакты в постоянном меню
- Админ-команды владельца: `/today` (записи на сегодня), `/week` (расписание на неделю)
- Автоматические напоминания клиентам за день до визита
- Уведомление владельцу о новых записях и отменах
- SQLite — база в одном файле, легко бэкапится и переносится

## Запуск

```bash
pip install -r requirements.txt
```

Создать файл `.env` рядом с `bot.py`:

```
BOT_TOKEN=токен_от_BotFather
OWNER_ID=ваш_телеграм_id
```

> Токен получается у [@BotFather](https://t.me/BotFather) — бесплатно.
> Свой Telegram ID можно узнать у бота @userinfobot.

```bash
python bot.py
```

## Структура

| Файл | Назначение |
|---|---|
| `bot.py` | Вся логика бота (aiogram 3, FSM) |
| `bookings.db` | База SQLite с записями (не публиковать) |
| `.env` | Токен и ID владельца (не публиковать!) |

## Кастомизация под клиента

Услуги и цены — в словаре `SERVICES`, время работы — в списке `TIMES`,
тексты меню — в обработчиках. Под бизнес клиента правится за 15 минут.
